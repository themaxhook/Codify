# Codify

Codify is a simple real-time collaborative code editor built as a learning project.  
The main goal of this project is to allow multiple users to join the same room and write code together in real time.

I built this project to understand how real-time collaboration works and to practice using React, Node.js, and Socket.IO.

## Features
- Multiple users can join the same room
- Real-time code synchronization
- User avatars with unique colors
- Clean and minimal user interface
- Code editor powered by CodeMirror

## Tech Stack
- React (Frontend)
- Node.js & Express (Backend)
- Socket.IO (Real-time communication)
- CodeMirror (Code editor)
